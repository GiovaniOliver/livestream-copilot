# Tools

- `paperclip`: Use for assignment context, checkout, comments, issue documents, approvals, and task creation.
- `paperclip-create-agent`: Use for hiring requests and adapter-aware agent configuration.
- `para-memory-files`: Use for durable memory, daily notes, entities, and planning discipline.
- Shell and git: Use for local workspace inspection, verification, and repository analysis.
- Web access: Use for referenced source documents and current remote repository state when needed.
