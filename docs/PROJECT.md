# Livestream-Copilot (FluxBoard)

**Project:** livestream-copilot
**Brand:** FluxBoard
**Tier:** main
**Status:** active
**Todo:** docs/TODO.md
**Updated:** 2026-10-07

FluxBoard is an agentic live-workflow copilot (OBS desktop companion, web dashboard, mobile app) that turns live sessions into structured, shareable assets (clips, social drafts, chapters, quotes) while they happen. The first supported workflow is `streamer` with `av` capture (see docs/workflows/FIRST_SUPPORTED_WORKFLOW.md).
